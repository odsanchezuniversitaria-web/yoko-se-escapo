# Yoko se escapó

Aventura 2D de exploración y supervivencia creada en Unity **6000.4.10f1**.

**[Jugar en navegador](https://odsanchezuniversitaria-web.github.io/yoko-se-escapo/)** · **[Descargar Android](https://github.com/odsanchezuniversitaria-web/yoko-se-escapo/releases/latest/download/Yoko-Android.apk)**

Yoko busca a Yimmy entre las ruinas de Bogotá. Usa el olfato, asimila mutaciones temporales y decide cómo sobrevivir. Cinco zonas, guardado por zona y dos desenlaces según la violencia.

## Controles

A/D o flechas: mover. Espacio: saltar / mantener para planear con mutación de ave. Shift: olfato. E: interactuar. J: atacar. Escape: pausa. Android incluye botones táctiles y requiere Android 8 o superior, ARM64.

## Proyecto

Abrir `Unity` con la versión indicada y cargar `Assets/Scenes/Yoko.unity`. El mundo se construye al ejecutar. La carpeta `site` contiene el build WebGL publicado por GitHub Actions. Instrucciones y alcance en [LEEME.md](LEEME.md).

Primera versión jugable compacta; el arte generado adapta las referencias y no las reproduce exactamente. Android compilado y firmado, pendiente de prueba en teléfono físico. Yoko es la única jugable; Yimmy es un personaje no jugable según el guion.

Biblia narrativa: Laura Daniela Rodríguez Bernal, Angie Jasbleidy Fajardo Valbuena y Leidy Yised Estupiñán Salazar. Créditos conservados dentro del juego. El documento original no se incluye en este repositorio.
